# warpix-arcade 仕様メモ v0.2「GAME A・B と 4 たいの ボス」

- **タグ**：`v0.2`（2026-10-20）
- **ひとこと**：PIXE INVADERS を お店の 看板の 台に みがいた。ARCADE は warpix-link で とどかなかった 人（50 代 いじょう・子ども）の ための 場所なので、「わかりやすくて たのしい」を さきに 考えた。むずかしさの えらびかたは、50 代が 子どもの ころ あそんだ **ゲーム&ウオッチの GAME A・GAME B**（本人と 会話で きめた。「おさんぽ」の ような なまえは 子どもむけ すぎ、こっそり かんたんに する しかけは「バカに してる ように 見える」ので なし）。ボスは 名前と 顔の ある 4 たいに。台の よこで ピクセが おうえん
- **前のバージョン**：[v0.1.1](v0.1.1.md) ／ [バージョン一覧](README.md)

## v0.1.1 からの変更

- **タイトル**（`invaders.js` の phase `title`）：台を おすと すぐには はじまらず、タイトル画面。「PIXE / INVADERS」、あるく インベーダー 5 ひき、**BOSS の ならび**（あった ボスは 顔と なまえ、まだの ボスは 灰色の かげと「？」）、`A HI 000000`・`B HI 000000`
  - 下に **GAME A（ふつう）・GAME B（はやい）** の ボタン。さいしょは さいごに えらんだ ほうに フォーカス。← → で えらんで Enter、ボタンを おす、画面を さわる（さいごに えらんだ ほう）で はじまる。Esc で とじても 点は なにも おきない
  - ゲームオーバーの あと（TAP TO RETRY が でる ころ）にも ボタンが でる。画面を さわれば おなじ GAME で もう いちど
  - 見出しに いまの GAME（`PIXE INVADERS GAME B`）
- **GAME B**：むずかしさを 3 ウェーブ さきから はじめる（`lvl = ウェーブ + 3`）。敵の 行進・弾の はやさ・うつ かず・ボスの HP と うつ 間かく が ぜんぶ その lvl で きまる。点も lvl ばい なので 高い。1 ウェーブめの 敵は 6px 下（y 24）から
- **ランキングは GAME ごと**：A は これまでの `warpix-ranking`、B は `warpix-arcade-ranking-b`（なまえ `warpix-rank-name` は きょうつう）。ゲームオーバーの 表は `GAME A BEST 5`
- **ボス 4 たい**（3・6・9・12 ウェーブ、そのあと また UFOさん から。HP は 20 ＋ lvl×2）。24×12 の からだに 顔（目・口・ほっぺ）を かさね、2 ばいで 描く。たおすと 目が ×に なって、ふらふら 上へ かえって いく
  | ボス | 見た目 | うごき | うつ |
  | --- | --- | --- | --- |
  | UFO-SAN（UFOさん） | シアンの 屋根の 白い UFO | 左右に 0.5＋lvl×0.05 | 3 ほうこう（よこ ±0.6）、max(36, 80−lvl×4) フレームごと |
  | TAKO（タコ） | ピンクの タコ、白い はちまき | 8 の 字（x は 56±50、y は ±4） | 5 ほうこうの すみ（ゆっくり 0.8＋lvl×0.04）、max(48, 100−lvl×4) |
  | KANI（カニ） | 金色、ぼうの さきに しろ目 | のそのそ 0.4、2.5 びょうごとに 自機の ほうへ ダッシュ（2.6×24 フレーム） | 両方の はさみから まっすぐ、max(30, 64−lvl×3) |
  | NEKO（ネコ） | 白ねこ、ピンクの 耳と ひげ | 3 びょうごとに 0.5 びょう きえて（はじめと おわりに ちらちら）、べつの ばしょに | 自機を ねらう 1 ぱつ（よこ ±1.2 まで）、max(34, 72−lvl×3) |
  - ボスの ウェーブの はじまりは 1.5 びょう、`BOSS WAVE!` の 下に 名前
  - たおした ボスは `warpix-arcade-bosses`（id の 配列）に のこり、タイトルで 顔が みえる
- **台の よこの ピクセ**（`#game-cheer`）：ゲームの 画面の 上に 小さな ピクセと 2 ぎょうの ふきだし（デモでは かくす）。うれしい ときは ぴょんと はねる
  - タイトル「GAME A は ふつう、GAME B は はやいよ。」／はじまり「いってらっしゃい！」（B は「GAME B だね。おてなみ はいけん！」）
  - ウェーブ クリア「ナイス！」「いい ちょうし！」「その ちょうし！」／ボスが でる：ボスごとの ヒント（例「タコが きた！ すみを ばらまくよ。」）／たおす「やった！ ◯◯を たおした！」
  - やられた「おっと！ まだ だいじょうぶ。」、のこり 1「あと 1つ。おちついて いこう。」、おわり「おつかれさま！ もう いっかい いく？」
- **受付**（`hall.js`）：台の HI を 2 ぎょう（`A 001234 KOY`・`B ------`）。あそび おわりの ひとことに GAME の 名前（「すごい！ GAME Bの ハイスコア こうしん！」）、ランキングに のらなくても ボスを たおして いれば「おつかれさま！ ボスを ◯たい たおしたね。」。おしゃべりに 2 つ（GAME B・ボスは 4たい）
- **このページについて**：あそびかたに GAME A・B と ボス、のこす ものに「ランキング（GAME A・B）」「あった ことの ある ボス」
- **けした もの**：`core.js` の `MOTHERSHIP`（ボスの 絵は `invaders.js` へ）
- `open()` は タイトルから、`open({ mode: "a" })` は すぐ はじまる、`open({ demo: true })` は デモ。`invaders.ranking("b")`・`bosses()`・`met()`
- 合図に GAME：`game-start`・`game-over`・`game-rank` に `mode`、`game-boss` に `boss`（id）
- 文字：`node tools/fonts.mjs`（417 文字、21.0 KB）
- `sw.js` の キャッシュ名 `arcade-v0.2.0`
