# warpix-arcade 仕様メモ v0.1「開店じゅんび」

- **タグ**：`v0.1`（2026-10-19）
- **ひとこと**：WARPIX製作所の 第二弾。**ピクセが まってる、レトロゲームの ゲームセンター**。プレ開店の 声で、「いつもの アプリや サイト」が ない 人（とくに 50 代 いじょう）には warpix-link が どう 工夫しても つたわらない と わかった。いっぽうで インベーダーと ピクセの かわいさは とどいた。だから とどいた ものを 主役に した べつの 入口を つくる（本人の 発案。企画は 事務所の `11-WARPIX-ARCADE.md`）
- **バージョン一覧**：[README](README.md)

## なかみ

- **PRESS START**（`index.html`・`hall.js`）：WARPIX-ARCADE の 文字と ひとこと「ピクセが まってる、／レトロゲームの ゲームセンター。」（せまい 画面では「、」で 2 行、かたまりは われない）。PRESS START か 画面の どこか・Enter・スペースで はいる。コイン → 0.18 びょう あとに 起動ジングル、店内 BGM は 0.9 びょう あとから。画面は 3 かい 点滅して きえる（0.45 びょう、動きを へらす 設定では すぐ）
- **店内 BGM**（`core.js`）：C → Am → F → G の 4 小節、BPM 150、8分音符 32 こ。リンク集の 曲とは べつ。BGM ボタンで オン・オフ、`warpix-arcade-bgm` に おぼえる
- **受付の ピクセ**（`hall.js`）：まばたき（2.5〜5.5 びょうごと）、メッセージウィンドウは 1 文字 35 ミリびょう、▼ で つぎへ
  - はじめて（`warpix-arcade-visits` が 1）：「いらっしゃい！ ここは ピクセの ゲームセンター。」「いまは まだ 1だい だけど、これから すこしずつ ふえるよ。」「すきな だいで あそんでってね！」
  - 2 かいめ から：「おかえり！ きょうも あそんでく？」＋ ハイスコアが あれば「PIXE INVADERS の ハイスコアは ◯てん。こえられるかな？」
  - つつくと おしゃべり 6 つ（コインは いらない・入荷の おしらせ・ドラッグ・なまえ 3 もじ・となりの へや・製作所の ゲームセンター）
  - あそび おわって ゲームの 画面が とじたら：1 い「すごい！ ハイスコア こうしん！」、2〜5 い「ランキングの ◯いに なまえが のったね！」、それ いがい「おつかれさま！ ◯てん だったね。」。0 てんは なにも いわない
- **台**（`hall.js` の `CABINETS`）：4 だい、スマホでも 2 れつ。看板・画面・レバーと ボタン・HI
  - PIXE INVADERS：画面で インベーダーが 2 コマ（0.8 びょう）。HI は ランキング 1 い（`HI 001234 KOY`、なければ `HI ------`）
  - COMING SOON が 3 だい：布の しまもようと「？」、「にゅうか まち」。おすと ピクセ「その だいは まだ ないしょ。にゅうかを おたのしみに！」
- **PIXE INVADERS**（`invaders.js`）：warpix-link の `game.js`（v1.0〜）を そのまま。160×144、3 ウェーブごとに ボス、ベスト 5 に なまえ 3 もじ。キーは リンク集と おなじ `warpix-ranking`・`warpix-rank-name`（ちがう アドレスなので まざらない。いずれ ひっこしで もってこられる ように）
- **このページについて**：あそびかた・ホーム画面・のこす もの（ランキングと なまえ・来た かい数・BGM、どこにも 送らない）・となりの へや
- **となりの へや**：フロアの 下に「となりの へや：WARPIX-LINK（リンク集） ▶」（おなじ タブで link.warpix.app へ）
- **ホーム画面アプリ**：`manifest.webmanifest`（ARCADE）、アイコンは 48×48 マスの ドット絵（インベーダーが うつる 台と ピクセ、`tools/icon.html` → `tools/shoot-icons.mjs`）。`sw.js` の キャッシュ名 `arcade-v0.1.0`
- 重さ：はじめて ひらく とき 11 リクエスト・約 96 KB（リンク集は 約 610 KB）
