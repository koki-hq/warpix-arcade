# warpix-arcade 仕様メモ v0.5「PIXE RUN 入荷」

- **タグ**：`v0.5`（2026-10-20）
- **ひとこと**：3 だいめの 台 **PIXE RUN**。本人の 案「マリオみたいな、RTA も できる ステージクリア（リンク集の ぼうけんの もっと 本格 バージョン）」。むずかしさは インベーダーと おなじ ゲーム&ウオッチの GAME A・B、RTA は 3 つめの **TIME**（タイムアタック）として 奥に。**ゲームオーバーは ない**（おちても とちゅうの はたから すぐ）。子どもあつかい する しかけ（こっそり かんたんに する など）は 入れない
- **前のバージョン**：[v0.4](v0.4.md) ／ [バージョン一覧](README.md)

## なかみ（`run.js`）

- 160×144、タイル 8px（よこ 20・たて 18）。地面は 15 行め から
- **タイトル**：「PIXE / RUN」、はしる ピクセを コロが おいかける、`TIME`（ベスト）・`CLEAR`（ぜんぶ クリアした かず）。下に GAME A（ふつう）・GAME B（はやい）・TIME（タイムを きそう）。← → と Enter、または ボタン
- **うごき**（1 フレーム = 1/60 びょう）：かそく 0.15、さいこう 1.5px（GAME B は ぜんぶ 1.25 ばい）、はなすと 0.8 ばい。じゅうりょく 0.22、ジャンプ −4.0（たかさ 約 4.5 マス）、はやく はなすと −1.6 で うちきり。さきに おした ジャンプと、足場から おちた すぐ あとの ジャンプが 6 フレーム きく
- **ステージ** 4 つ（`build()` で 地面・れんが・？ブロック・土管・かいだん・コイン・敵・はたを ならべる）
  - 1-1 たいらな みち：はじめの ？ブロックは スタートの 真上、はじめの 敵は ひとり。あなは 2〜3 マス。中間の はた 1 つ
  - 1-2 土管と あな：**ひみつの ワープ土管**（2 ばんめの 土管の 上で ↓ → 104 マスめへ）
  - 1-3 そらの しま：うかぶ れんがを わたる。はた 2 つ
  - 1-4 さいごの みち：かいだん・敵 おおめ・さいごは 6 だんの かいだん
- **敵 コロ**（水色）：0.4px で あるき、かべで ふりかえる（あなには おちる）。画面から 200px より とおい ときは まつ。上から ふむと ぺたんこ（はねかえり −2.8）、よこから ぶつかると ミス
- **？ブロック**：下から たたくと コイン（U に かわる）。**コイン**：さわると ＋1
- **ミス**（あなに おちる・敵に ぶつかる）：「OOPS!」0.8 びょう → さいごに さわった はた（なければ スタート）から。たおした 敵と とった コインは そのまま。かずは 右上と さいごに
- **ゴール**：はたに タッチで STAGE CLEAR とタイム、2.5 びょうで つぎ。1-4 の あとは ALL CLEAR（TIME・COIN・OOPS）と モードの ボタン
- **TIME**：右上に つうさんの タイム。ステージごとの ベストより はやければ ベストと **ゴースト**（2 フレームごとの いち）を のこし、つぎからは うすい ピクセ（35%）が いっしょに はしる。STAGE CLEAR に ベストとの さ（`-0.50` シアン／`+1.23` ピンク）。ぜんぶの タイムが ベストなら NEW RECORD
- **スマホ**：さわれる 画面（`navigator.maxTouchPoints`・`pointer: coarse`）だけ、画面の 下に ◀ ▶（64px）と JUMP（96px、ピンク）。おして いる あいだ きく
- きろく `warpix-arcade-run`：`{ clears, best, splits: [4], ghosts: [4] }`
- 合図：`run-start`（`{ mode }`）、`run-stage`（`{ stage, frames, mode }`）、`run-clear`（`{ mode, frames, coins, misses, best }`）
